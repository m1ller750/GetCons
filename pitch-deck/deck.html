Technology

Real AI, honest “training”

Every customer message runs through a grounded pipeline. Saving knowledge never pretends to retrain the model, and every change applies to the very next message.

1 · MessageText, photo or voicefrom WhatsApp, Telegram or the website chat, queued per chat
→
2 · RetrieveHybrid searchGemini embeddings + pgvector + full-text, fused with RRF
→
3 · PersonaliseFew-shot + memorymost similar owner examples, recent history and a rolling summary
→
4 · ReasonGemini + toolsstructured reply with confidence and sources; on Pro, store tools by function calling
→
5 · DecideAnswer · act · hand offcustomer-confirmed actions, owner alerts, everything logged

Why not fine-tuning?

  • The Gemini API offers no fine-tuning for current models (Google docs, Oct 2026).
  • Prices and stock change daily, so they belong in retrieval, not model weights.
  • RAG + few-shot is instant, editable, auditable and cheap per tenant.

Stack

  • Google Gemini: 3.1 Flash-Lite with a 3.5 Flash-Lite backup, embeddings, OCR; xAI Grok as a reserve provider
  • Supabase: Postgres, pgvector, Auth, Row Level Security
  • Channels: WhatsApp linked devices, Telegram Bot API webhooks, an embeddable web chat
  • Railway: always-on container, zero-downtime deploys

Trust & reliability

Built to be trusted with real customers

Grounded answers

Business facts come only from the owner’s data and the live store catalog. Each reply records the passages it cited.

Honest fallback & handoff

When unsure, it promises to check. Complaints go to a human. The owner gets an alert in WhatsApp or Telegram with a link.

Safe actions

Orders, cancellations and refunds run only after the customer confirms in the chat. Big refunds wait for the owner. Every action is logged.

Strict data isolation

Postgres row-level security, trigger-derived ownership, and no client writes. Each business sees only its own data.

Secrets protected

Bot tokens, WhatsApp sessions and store keys are encrypted with AES-256-GCM. Store calls are signed and go to public HTTPS only.

Tested & resilient

149 automated tests. Idempotent webhooks, retries with backoff, a backup model and provider, rate and daily limits.
